# 统一 Token 压缩模块实验（2026-10-11）

已实现 14 个统一方法入口（含 off），并完成材料压缩、工具加载、来源补读、前缀复用和历史窗口的验证。推荐默认使用 `structure`；需要文本选段时可显式启用 `extract` 并提供补读入口。

本报告区分本地变换、真实本地模型推理和真实远程问答。数据均为合成材料，不代表生产流量、费用节省或通用语义无损性。

## 本地材料对照

10 类样例 × 7 种方法 × 3 次重复，共 210 次变换。每次都检查保护字段、指定关键事实、来源恢复和实际请求长度；210/210 通过。token 采用 o200k tokenizer 对序列化请求计数，属于本地估算。重复使用各方法缓存，比例按输入 token 总量加权。

| 方法 | 输入估算 token | 输出估算 token | 降幅 | 中位耗时（ms） |
| --- | ---: | ---: | ---: | ---: |
| off | 136,422 | 136,422 | 0.00% | 0.754 |
| structure | 136,422 | 71,037 | 47.93% | 4.537 |
| caveman | 136,422 | 68,157 | 50.04% | 5.881 |
| extract | 136,422 | 44,232 | 67.58% | 5.035 |

`caveman`、`extract` 等方法均包含结构优先阶段。日志样例中，部分方法的裸文本候选更短，但 JSON 转义后完整请求变长，因此 3 次重复都回退原文；这是收益检查生效，并非按负节省输出。`headroom` 使用实际原生包和内容路由，关闭自动模型下载。

## 可选本地模型

LLMLingua-2 和 NLP 使用英文、中文、代码 3 个样例，各重复 2 次；MLM 使用较短英文样例重复 2 次，避免把逐词前向推理成本隐藏在大型样例中。不同数据集的比例不能直接排名。

| 方法 | 样例 × 重复 | 加权本地降幅 | 关键证据检查 |
| --- | ---: | ---: | ---: |
| llmlingua2 | 3 × 2 | 43.81% | 6/6 |
| caveman_nlp | 3 × 2 | 23.75% | 6/6 |
| caveman_mlm | 1 × 2 | 10.53% | 2/2 |

真实 CPU 推理：LLMLingua-2 首个英文样例约 16.1 秒，中文约 16.6 秒；NLP 首个英文约 1.1 秒；MLM 首次约 23.3 秒。缓存命中耗时不代表冷启动。代码样例主要由结构阶段压缩，不能当作神经模型删词成功的证据。NLP 使用英文 spaCy 模型，中文样例没有取得该后端的额外收益。

证据：[本地模型](final/models/results.json)、[MLM](final/mlm/results.json)。LLMLingua-2 使用缓存 revision `ebaba9b0e874dadd3003ffcff828e4397e568089`；RoBERTa 使用 `e2da8e2f811d1448a5b465c236feacd80ffbac7b`。包版本、CPU 配置和模型目录见各 `run_config.json` / `results.json`；权重未提交。

## 会话与工具实验

- 前缀：第二轮精确重放 3 条历史消息；编辑历史后复用数归零。没有声称已证明服务商缓存命中。
- 补读反馈：同工具 5 个不同来源均补读后，下一条材料只进行结构压缩。
- 工具定义：30 个完整 schema 为 8,012 个本地估算 token；1 个常驻工具加目录为 1,000，首请求少 7,012（87.52%）。加载一个工具的返回为 297 token，schema 与原值完全一致。目录、调用和重加载的最终任务成本不能用首请求节省代替。
- 历史窗口：6,559 → 1,651 个本地估算 token；开头系统消息和最近两轮保持一致，删除的 6 轮可由来源库完整恢复。
- 回归覆盖：两种请求协议、未知/畸形 JSON、数值字面量、多模态保护、源存储配额、失败退避、损坏标记、差量依赖展开、伪造 envelope 不被解码、代理 usage 与工具 schema 往返。
